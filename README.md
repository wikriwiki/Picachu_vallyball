# 인생게임 온라인 (the Game of LIFE for Nintendo Switch 스타일)

타카라토미 「인생게임 for Nintendo Switch」의 구조를 따라 만든 **온라인 멀티플레이 3D 보드게임**입니다.
친구끼리 방 코드 하나로 최대 4명(빈 자리는 CPU)까지 함께 플레이할 수 있습니다.

- **렌더링**: Three.js + 커스텀 GLSL 셰이더
  - 툰 셰이딩(3단 셀 + 그림자맵 + 반구광 + 림라이트 + 스텝 하이라이트), 뒤집힌 헐 아웃라인
  - 보드 칸: 인스턴싱 + 아이콘 아틀라스 + 활성 칸 펄스 셰이더
  - 바다: 다중 파도 정점 변위 + 프레넬 + 해안 거품 + 코스틱
  - 하늘: 그라데이션 + 태양 + fbm 구름
  - 룰렛: 극좌표 세그먼트 + 각속도 기반 모션 블러
  - 색종이 파티클(GPU 궤적), 후처리(블룸 → 틸트시프트 미니어처 + 비네트 + 컬러 그레이딩)
- **멀티플레이**: Node.js + WebSocket(`ws`) 서버 권위 방식. 끊겨도 같은 탭에서 자동 재접속되며, 접속이 끊긴 플레이어의 차례는 몇 초 뒤 자동으로 진행됩니다.

## 실행

```bash
npm install
npm start          # http://localhost:3000
```

같은 와이파이의 친구는 `http://<내 PC IP>:3000` 으로 접속하면 됩니다.

### 인터넷으로 친구와 하기

**방법 1 — Render(무료) 배포**: 이 저장소를 Render에 연결하면 `render.yaml` 설정으로 바로 배포됩니다.
(New → Blueprint → 저장소 선택). 배포된 주소를 친구에게 공유하세요.

**방법 2 — 내 PC에서 터널**: `npm start` 후 다른 터미널에서

```bash
npx cloudflared tunnel --url http://localhost:3000
```

출력된 `https://....trycloudflare.com` 주소를 친구에게 보내면 됩니다.

## 플레이 방법

1. 닉네임과 아바타를 정하고 **방 만들기** → 4자리 방 코드/초대 링크를 친구에게 공유
2. 친구는 코드를 입력하고 **참가하기** (초대 링크로 들어오면 코드가 자동 입력됨)
3. 방장이 필요하면 **CPU 추가** 후 **게임 시작!**
4. 내 차례에 **SPIN 버튼을 누르고 있다가 떼면** 룰렛이 돌아갑니다(스페이스바도 가능).

## 게임 규칙 요약

| 항목 | 내용 |
|---|---|
| 시대 | 아기(2턴) → 초등학생(4턴) → 중학생(4턴) → 고등학생(4턴) → 어른 전반(7턴) → 어른 후반(7턴) → 마지막 시절(골까지) |
| 능력치 | 지력·체력·센스 (G~S 등급) + 운세(대흉~초대길) |
| 동아리 | 중·고등학생 시대 시작 시 선택 (능력치 성장) |
| 진로 | 고교 졸업 시 대학 진학(학비, 지력↑) / 바로 취직 |
| 직업 | 17종. 능력치 승진형(월급날 자동 승진) / 룰렛 승진형(랭크업 찬스 칸) / 프리랜서(월급 룰렛) |
| 칸 | 이벤트·럭키·월급날(지나가도 지급)·연애·아찔·선택·카드·랭크업 찬스·아기·STOP(결혼, 내 집 마련) |
| 카드 | 지정 룰렛, 더블, 보험(자동), 보너스, 학습/헬스/아트, 부적, 가로채기, 승진 |
| 약속어음 | 돈이 모자라면 1장(1000만) 자동 발행, 결과 발표 때 1장당 1200만 상환 |
| 결과 발표 | 현금 + 보물 감정 + 집 감정 + 자녀 효도 + 골 순위 보너스 + 특별상 − 약속어음 |

게임 모드: 인생 모드(전체) / 어른 모드(어른부터, 능력치 랜덤) / 어린이 모드(고등학생까지).

> 확인된 원작 수치(회사원·의사 직급/월급, G~S 등급, 7개 시대 구성 등) 외의 수치는 추정값입니다.
> 모든 수치는 `shared/data.js` 에서 조정할 수 있습니다.

## 구조

```
server/index.js    HTTP 정적 서버 + WebSocket
server/rooms.js    방/로비, 턴 타이머, CPU·오프라인 자동 진행
shared/data.js     시대·직업·카드·이벤트 데이터
shared/board.js    보드 칸 배치 (서버/클라이언트 공통)
shared/engine.js   룰 엔진 (서버 권위, JSON 상태)
public/js/world.js    3D 월드 (섬, 보드, 말, 카메라, 후처리)
public/js/shaders.js  GLSL 셰이더
public/js/roulette.js 3D 룰렛
public/js/main.js     UI · 네트워크 · 이벤트 연출
```
